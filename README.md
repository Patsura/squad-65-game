# Squad 65

Небольшая браузерная игра про сбор футбольного отряда из 4 игроков без сборки и внешних зависимостей.

## Возможности

- Обновлённый лёгкий игровой интерфейс с визуальными карточками, аватарами и выделением последнего открытия.
- Ящики за монеты с игроками рейтинга 60–99.
- Игроки получают позиции: `ВР`, `ЗЩ`, `ПЗ`, `НП`.
- Отряд из 4 игроков, автоподбор лучшего состава и бонус `+10` за 4 разные позиции.
- Турниры с интерактивными матчами, наградами, RP, рангами и трофеями.
- Ежедневный бонус: `+3` монеты один раз в день.
- Сохранение прогресса в браузере: монеты, RP, игроки, отряд, трофеи и журнал.
- Кнопка `Новая игра` полностью сбрасывает локальный прогресс.

## Запуск

Открой `index.html` напрямую в браузере.

Или запусти локальный сервер:

```bash
node server.mjs
```

Адрес игры:

```text
http://127.0.0.1:4173
```
