# Squad 65

Небольшая мобильная-first браузерная игра про сбор футбольного отряда из 4 игроков без сборки и внешних зависимостей. Интерфейс оформлен как лёгкая премиальная sports-card mini-game с нижней навигацией, коллекционными карточками и быстрым фокусом на составе.

## Возможности

- Mobile-first UI: компактный HUD, нижняя навигация, улучшенные карточки состава и быстрые CTA.
- Анимированное открытие ящиков: карточная рубашка, shake/glow, reveal-flash и финальный экран награды.
- Стилизованные генерируемые портреты игроков на CSS/HTML без внешних картинок и шрифтов.
- Портреты и акценты зависят от позиции: `ВР`, `ЗЩ`, `ПЗ`, `НП`.
- Редкость карт визуально различается: обычные, редкие, элитные и легендарные с премиальным свечением.
- Ящики за монеты с игроками рейтинга 60–99 и разным визуальным стилем для Bronze/Silver/Gold/Legendary.
- Отряд из 4 игроков, автоподбор лучшего состава и бонус `+10` за 4 разные позиции.
- Турниры с интерактивными матчами, наградами, RP, рангами и трофеями.
- Ежедневный бонус: `+3` монеты один раз в день.
- Сохранение прогресса в браузере: монеты, RP, игроки, портреты, отряд, трофеи и журнал.
- Кнопка `Новая игра` полностью сбрасывает локальный прогресс.

## Запуск

Открой `index.html` напрямую в браузере.

Или запусти локальный сервер:

```bash
node server.mjs
```

Адрес игры:

```text
http://127.0.0.1:4173
```

Проект остаётся полностью vanilla HTML/CSS/JS: нет npm-пакетов, внешних изображений, внешних шрифтов и build step.
