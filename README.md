# Squad 65

Небольшая mobile-first браузерная игра про сбор отряда из 4 героев без сборки и внешних зависимостей. Интерфейс переработан в оригинальном премиальном fantasy-strategy стиле: тёмная цитадель, золотые рамки, каменно-пергаментные панели, магические свечения, сундуки-реликварии и героические коллекционные карты.

Дизайн вдохновлён атмосферой классических фэнтези-стратегий, но не использует и не копирует чужие ассеты, логотипы, шрифты, иконки, скриншоты или интерфейсные элементы. Всё оформление сделано только на HTML/CSS/JS.

## Возможности

- Mobile-first UI: компактный fantasy HUD, нижняя навигация, быстрые CTA и читаемые панели на телефоне.
- Отряд героев из 4 слотов с автоподбором лучшего состава и бонусом `+10` за 4 разные роли.
- Коллекционные hero-card карты с CSS-портретами, медальонными рамками и редкостью: обычные, редкие, элитные и легендарные.
- Сундуки за золото: бронзовый сундук, серебряный ларец, золотой сундук и легендарный реликварий.
- Магическое открытие сундуков: сначала реликвия, затем reveal карты, glow/pulse/shimmer эффекты и текст награды.
- Испытания с тактическими решениями, наградами, RP, титулами и трофеями-реликвиями.
- Ежедневный дар: `+3` золота один раз в день.
- Сохранение прогресса в браузере: золото, RP, герои, портреты, отряд, трофеи и журнал.
- Кнопка `Новая игра` полностью сбрасывает локальный прогресс.

## Запуск

Открой `index.html` напрямую в браузере.

Или запусти локальный сервер:

```bash
node server.mjs
```

Адрес игры:

```text
http://127.0.0.1:4173
```

Проект остаётся полностью vanilla HTML/CSS/JS: нет npm-пакетов, внешних изображений, внешних шрифтов и build step.
