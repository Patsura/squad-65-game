# Squad 65

Небольшая браузерная игра про сбор отряда из 4 игроков.

## Что есть

- Персонажи с рейтингом от 60 до 99.
- 4 ящика за монеты: 2, 4, 5 и 6 монет.
- Отряд из 4 игроков.
- 3 турнира: Чемпионат мира, Лига чемпионов и Кубок континентов.
- Интерактивный матч с решениями по ходу игры.
- Система из 15 рангов от `Новичок I` до `Чемпион 99`.

## Запуск

Можно открыть `index.html` напрямую в браузере.

Либо запустить локальный сервер:

```bash
node server.mjs
```

После этого игра будет доступна по адресу:

```text
http://127.0.0.1:4173
```
